# Verano Heat

An original sun-soaked open-world crime game for the make.fun "Make GTA 6" bounty: the city of Puerto Verano — explore it on foot and by car, steal and drive its traffic, run a chain of story missions, and outrun a five-star police response. Static files under `game/`, no build step; `node serve.ts` plays it locally.
